AL MUSHREF website update - Abaya Size Guide

1. Extract this ZIP on your computer.
2. Open your ahalmn/almushreftailoring repository on GitHub.
3. Choose Add file > Upload files at the repository root.
4. Upload the CONTENTS of the extracted folder, including the assets folder.
   Do not upload an enclosing AL_MUSHREF folder.
5. Replace matching files and commit the changes.
6. Wait for the GitHub Pages deployment to finish, then refresh your website.

index.html must sit directly in the repository root. Keep all assets together.
The size guide is linked from the menu, catalogue, footer, and Abaya details.
Sizing suggestions are approximate; confirm garment length and width before ordering.
